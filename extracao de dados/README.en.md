# Data extraction
[Português brasileiro](README.md) · [Full guide](../docs/en/GUIDE.md)

From the root: `python3 "extracao de dados/extrair_tudo.py"`. Requires Python 3 and internet; uses the standard library. Individual scripts can be run the same way using their filenames.

Extractors save public data and manifests under `dados/`. OSD-569/575 contain human labs; OSD-654/662 are animal studies; OSD-13/323 use human cells; RadLab is environmental radiation and JAXA ICE is an experiment. Check manifests before interpreting values. Refreshing may overwrite the current snapshot.
