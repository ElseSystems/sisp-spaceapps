# Extração de dados
[English](README.en.md) · [Guia completo](../docs/pt-BR/GUIA.md)

Na raiz: `python3 "extracao de dados/extrair_tudo.py"`. Requer Python 3 e internet; usa biblioteca padrão. Os scripts individuais podem ser executados da mesma forma pelo nome.

Os extratores salvam dados públicos e manifestos em `dados/`. OSD-569/575 são exames humanos; OSD-654/662 são animais; OSD-13/323 são células humanas; RadLab é radiação ambiental e JAXA ICE é experimento. Confira os manifestos antes de interpretar valores. Uma nova extração pode sobrescrever a cópia atual.
